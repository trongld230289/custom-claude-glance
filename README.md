## Install

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/trongld230289/glanceline/main/install.ps1 | iex
```

macOS / Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/trongld230289/glanceline/main/install.sh | bash
```

Needs Python 3.8+ and git.
